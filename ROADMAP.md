# 24-Month Roadmap

## Phase 1 — Foundations

- AWS Solutions Architect fundamentals
- AWS networking and IAM labs
- Terraform fundamentals
- Bash and Python automation
- Consistent GitHub documentation

## Phase 2 — Security Engineering

- AWS Security
- Security Hub / GuardDuty / Config
- Policy-as-code
- GCP Security
- CI/CD security controls

## Phase 3 — Cloud Native

- Kubernetes
- CKA preparation
- Kubernetes security
- CKS preparation
- Admission control and runtime security

## Phase 4 — International Job Readiness

- Multicloud flagship project
- Technical writeups in English
- Architecture interviews
- Security engineering interviews
- CV and LinkedIn optimization

## Operating principle

The roadmap is not a certification checklist. Each phase should produce visible evidence: code, diagrams, notes, labs, automation and technical explanations that can be discussed in an interview.
