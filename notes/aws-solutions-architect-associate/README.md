## Purpose

These notes are not a transcript of the course. They document the concepts I can explain, the architecture decisions I understand, and the practical work I reproduce independently.

## Study workflow

For each meaningful topic:

1. Write the topic name.
2. Explain the concept in my own words.
3. Record the AWS services involved.
4. Note an architecture or security decision.
5. Add a practical test or lab when useful.
6. Record mistakes, confusing points and fixes.
7. Finish with an interview-style explanation.
